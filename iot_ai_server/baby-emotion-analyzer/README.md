# 婴幼儿面部表情分析

基于 **MediaPipe FaceLandmarker** + **几何规则引擎** 的婴幼儿面部表情识别工具。通过分析面部关键点的几何特征（眉毛、眼睛、嘴角等），对婴幼儿的面部表情进行启发式解读，识别 5 类常见状态：**平静 / 开心 / 困倦 / 烦躁 / 身体不适**。

>  针对婴幼儿做了专门适配：表情幅度比成人小，规则阈值经过专门校准；对小人脸、暗光、侧脸等场景有多种增强策略提高检出率。

 无需预训练模型权重，即开即用
 支持批量图片 / 单张图片 / 摄像头实时
 输出带关键点和情绪概率条的可视化结果



### Windows（推荐）
双击 `run.bat`，首次运行会自动安装依赖。

### 命令行
```bash
# 安装依赖（仅需一次）
pip install -r requirements.txt

# 1) 批量分析 (默认扫描 imgs/baby/)
python baby_emotion.py

# 2) 指定目录
python baby_emotion.py --input imgs/baby --output output

# 3) 单张图片
python baby_emotion.py --image path/to/baby.jpg

# 4) 摄像头实时
python baby_emotion.py --camera 0
```

##  环境要求

- **Python** 3.9 ～ 3.13
- **依赖**：mediapipe, opencv-python, numpy（pip 自动安装）
- **平台**：Windows / macOS / Linux

##  关于图片

- 支持格式：`.jpg` / `.jpeg` / `.png` / `.bmp` / `.webp`
- 把婴幼儿照片丢到 `imgs/baby/` 目录即可，**不需要**手动改代码
- 分辨率越清晰、正面人脸，分析效果越好
- 婴幼儿表情幅度比成人小，规则引擎的阈值对此做了专门校准

##  技术原理

```
输入图片 → MediaPipe 478 关键点 → 6 个归一化几何特征 → 规则引擎打分 → 5 类情绪概率
```

1. **关键点检测**：MediaPipe FaceLandmarker 输出 478 个面部关键点；针对婴幼儿照片人脸小/暗光/侧脸问题，采用原图 → 放大 1.5× → CLAHE 对比度增强 → 直方图均衡化 多策略重试，提高检出率

2. **几何特征**（均除以脸宽归一化，不受人脸大小影响）：
   - 眉间距（皱眉 ↓）、眼睛开合度（困倦 ↓）、嘴张开度、嘴宽度（笑 ↑）
   - `smile_score`（嘴角上扬为正、下拉为负）、嘴宽高比（抿嘴小、张嘴大）

3. **规则打分**：5 类情绪各有启发式规则，用 sigmoid / 高斯函数组合打分，softmax 归一化后取最高者：
   - 开心 = 微笑 + 眼稍眯 + 嘴宽
   - 困倦 = 眼闭合 + 嘴闭
   - 烦躁 = 眉内聚 + (嘴抿 **或** 张嘴)
   - 不适 = 嘴角下拉 + 皱眉 + 可能张嘴
   - 平静 = 各特征落在中性区间

4. **可视化**：输出图标注 22 个关键点、预测情绪 + 置信度、5 类情绪概率条

##  5 类面部表情说明

| 情绪 | 典型面部表现 | 对应需求场景 |
|------|-------------|-------------|
| 😐 **平静** | 眉毛舒展、眼睛正常睁开、嘴微闭、嘴角水平 | 正常状态 |
| 😊 **开心** | 嘴角上扬呈微笑、眼睛稍眯、脸颊自然抬起 | 愉悦、满足 |
| 😴 **困倦** | 眼睛闭合或半闭、嘴紧闭、面部肌肉放松 | 想睡觉、疲惫 |
| 😠 **烦躁** | 眉毛内聚下压、嘴紧抿或张嘴哭喊、面部紧绷 | 哭闹、不满 |
| 😣 **身体不适** | 嘴角下拉、皱眉、可能张嘴呻吟 | 饥饿、疼痛、不舒服 |

##  已知事项

- 置信度在合成/简笔画图片上会偏低（~20%~30%），**真实人脸通常能到 60%~90%**
- MediaPipe 1.0 退出时的 `TypeError: 'NoneType' object is not callable` 是官方析构函数的已知无害警告，不影响结果

##  可扩展方向

若有标注好的婴幼儿情绪数据集，可直接把 `score_emotions()` 规则引擎替换为训练好的分类器（XGBoost / 小型 MLP），特征部分保持不变。
